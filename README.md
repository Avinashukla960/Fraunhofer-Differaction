🌊 Fraunhofer Diffraction Pattern Simulator

This project is a web-based simulation of the Fraunhofer Diffraction pattern, built using HTML, CSS, and JavaScript. It visually demonstrates how light behaves when it passes through a slit and forms an interference pattern.

🔗 Live Demo:
👉 https://avinashukla960.github.io/Fraunhofer-Differaction/
📌 About the Project

The Fraunhofer Diffraction phenomenon is an important concept in physics that explains the wave nature of light.

This project helps in:

Visualizing diffraction patterns
Understanding intensity distribution
Learning through interactive simulation
