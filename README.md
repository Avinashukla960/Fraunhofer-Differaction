🌊 Fraunhofer Diffraction Pattern Simulator

This project is a web-based simulation of the Fraunhofer Diffraction pattern, built using HTML, CSS, and JavaScript. It visually demonstrates how light behaves when it passes through a slit and forms an interference pattern.
